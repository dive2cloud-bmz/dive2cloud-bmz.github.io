Agent 记忆系列（05）· 技术雷达：从 CoALA 论文到产业落地的三年演进

一篇 CoALA 论文的「续集」：论文点出方向之后，社区和商业公司把「记忆」这块拼图修成了什么样，现在走到哪，又要往哪去。

时间基准：2026 年 7 月

引子：一篇论文如何变成一个赛道

2023 年 9 月，普林斯顿的 CoALA 论文把「记忆」正式抬进了语言智能体的架构中心——它把记忆分成工作、情景、语义、程序性四类，并把「学习」重新定义为「向长期记忆写入」。当时这还只是一张理论地图，真正能长期记住东西的 Agent 几乎没有。

三年后的今天，「Agent Memory」已经是一个有独立创业公司、有专门 market map、有专属评测基准、有云厂商托管服务的完整赛道。这篇技术雷达，就是要梳理这段「从论文到产业」的演进：它经历了哪几个阶段，社区和商业公司现在是什么格局，以及下一步往哪走。

第一阶段（2023）：记忆 ≈ 把历史塞进上下文

CoALA 发表的那个时间点，主流做法还很朴素——所谓「记忆」，基本等于「把对话历史或检索到的文档 chunk 塞进上下文窗口」。这其实就是 RAG 的直接套用：向量化、查相似、拼进 prompt。

这个阶段的问题很快暴露：上下文窗口塞满了噪声，token 成本高、延迟大，而且模型经常「记不住重点」——因为它存的是原始对话，而不是提炼后的事实。CoALA 框架此时的价值在于：它明确告诉大家，记忆应该是一个有结构的独立模块（分四类、有读有写），而不是往上下文里堆原文。方向指明了，但工程实现还没跟上。

MemGPT 是这一阶段末尾的关键转折。它提出把 LLM 当操作系统，用「虚拟内存分页」的思想在有限上下文和外部存储之间换入换出——第一次让「记忆管理」成为一个被认真对待的系统工程问题。它后来演化成了创业公司 Letta。

第二阶段（2024）：抽取 + 更新，记忆开始「懂事」

2024 年是范式确立的一年。核心转变是：记忆从「存原话」进化到「抽事实 + 冲突消解」。

标志性的代表是 mem0（YC S24 批次）。它确立了那套后来被广泛采用的流水线：用 LLM 从对话里抽取「精炼后的事实」，每条新事实再与最相似的既有记忆比对，由 LLM 决定执行 ADD（新增）/ UPDATE（增强）/ DELETE（矛盾则删）/ NOOP（不动）——这正是 CoALA 说的「学习 = 向长期记忆写入」的工程化实现。它还提出了 user / agent / session / app 四级作用域，解决了「记忆归谁、给谁看」的隔离问题。

同一年，Letta 带着 MemGPT 血统正式创业（$10M 种子轮，Felicis 领投），把记忆做成可被 Agent 自己编辑的 Memory Blocks；Zep 则从对话记忆转向知识图谱路线，孵化出开源引擎 Graphiti。LangChain 也把长期记忆能力沉淀成 LangMem SDK，并把 CoALA 的三分法（语义/情景/程序性）讲得清清楚楚。

这个阶段结束时，「记忆是一条抽取—更新流水线」已经成为社区共识。

第三阶段（2025-2026）：混合检索、时序图谱与「一等公民」

进入 2025 年下半年到 2026 年，赛道完成了又一次跃迁，几个趋势同时发生：

记忆升格为「一等架构组件」。 mem0 在 2026 年的报告里明确宣告「Memory is a first-class architectural component」——记忆不再是 RAG 的附属检索环节，而是与推理、规划平级的架构主体。这正是 CoALA 三年前的主张被产业正式接受的时刻。

检索从纯向量转向多路混合。 头部方案一致走「语义相似 + BM25 关键词 + 实体/图」的三路融合，纯向量被证明不够用。mem0 2026 新算法就是三路并行打分融合。

时序知识图谱成为高端分水岭。 Zep 的 Graphiti 采用双时序模型——每条关系同时记「事件何时发生」和「数据何时被摄入」，冲突时标记失效而非删除，从而能回放任意历史时刻的知识状态。这种时序推理能力，是纯向量记忆无论如何做不到的，也成了区分「玩具」和「企业级」的标尺。

大厂把记忆做成消费级标配。 2025 年，OpenAI（Reference chat history）、Anthropic（Claude 项目级记忆）、Google（Gemini Personal Context）先后把跨会话记忆做成默认功能。记忆从「开发者才关心的基础设施」变成了亿级用户的日常预期。

记忆能力向数据库层下沉。 云厂商开始把整条记忆流水线（含 LLM 抽取）打包成数据库托管服务——阿里云 RDS PostgreSQL / PolarDB 的 mem0 长期记忆就是典型，对用户呈现为「数据库的记忆 API」，底层是 pgvector + 图 + 全文的融合。

社区现状：开源热度与格局

用开源热度这把尺子量，当前格局大致如下（GitHub stars，2026-07 快照）：

项目 Stars 定位 特点
mem0 ~61k 通用记忆层 断层第一，事实标准，PyPI 约 330 万次/月
Graphiti (Zep) ~29k 时序图记忆引擎 技术上限最高，基准领先
Cognee ~29k 图向量混合 「Just Postgres」单库跑全栈
Supermemory ~28k 记忆与上下文引擎 增长最快的新星，多模态
Letta ~24k 自编辑记忆 MemGPT 血统，记忆可编辑
Memobase ~3k 用户画像式记忆 重 SQL 轻向量
LangMem ~1.6k LangChain 记忆 SDK 依附 LangChain 生态分发

社区的一个有趣特征是：几乎所有头部项目都有开源内核。这个赛道没有走「纯闭源算法」的路线——大家默认用开源建立开发者心智，商业化靠的是别处（见下）。

评测层面，社区围绕 LOCOMO、LongMemEval 等基准展开竞赛，但有一个必须清醒认识的现状：绝大多数 SOTA 高分都是厂商在自己博客里自评的，数据集版本和口径不统一，缺乏统一第三方裁判的横向复现。看到「某某在 LOCOMO 上 96%」这类数字时，要留意它是不是自报成绩。

商业公司现状：两个赛道，各有王者

商业化层面，市场分成两条清晰的赛道。

赛道一：大厂内置记忆（闭源，用户量最大）。 OpenAI ChatGPT Memory 是消费端体量之王（8 亿周活），技术形态是「saved memories 结构化事实 + dreaming 跨会话检索」的混合架构。但它们有个共同特点——记忆都是产品内置功能，不对外提供独立 memory API。四家的差异化路线各不相同：OpenAI 走消费级全局画像，Anthropic Claude 走项目级隔离和企业隐私优先，Google Gemini 接个人 Google 生态（但暂不含 Workspace 商业版），微软 Copilot 则封闭在 M365 企业租户内。

赛道二：记忆平台与云服务（开源内核 + 商业托管）。 这条赛道的两强是 mem0 和 Zep。mem0 胜在生态最广、第三方评测综合领先、融资最多（$24M），托管版 Pro 卖 $249/月；Zep 胜在时序图谱技术最强、企业治理最完整（ABAC、审计、事实溯源、SOC2/HIPAA），拿到了 S&P Global 分析师「可能成为企业 Agent 记忆层事实标准合作方」的背书。云厂商这一层，AWS 有自研的 Bedrock AgentCore Memory，阿里云则把 mem0 做成 RDS PG/PolarDB 的原生托管服务（按记忆量计费，约为 mem0 商业版的一半价格）。

综合来看，头部商业产品有七个共性特征：两层记忆架构（短期+长期）、从存原话到抽事实、图谱作为高端差异化、token 效率作为核心卖点、企业级治理作为商业护城河、「开源内核+托管+企业版」的三级商业模式、以及隐私可控作为营销点。

值得点出的一个洞察是：在这个赛道，「闭源」几乎是个伪命题。 做得最好的 mem0 和 Zep 都是开源内核 + 商业托管，卖的是托管、治理、SLA 和规模，而不是闭源算法。真正纯闭源的只有大厂内置记忆。

未来发展方向

回到 CoALA 当年点名的清单，对照今天，可以看到几个明确的演进方向——有些已在路上，有些还是空白：

方向一：时序与「演进」建模的规模化。 双时序图谱已证明有效，但在千万级记忆上高效做时序推理仍是难点。如何把「信息变化」建模为「演进」而非简单「替换」，是下一个技术高地。

方向二：异步巩固（Sleep-time Compute）。 把记忆的整理、压缩、去冲突从「用户请求时算」挪到「空闲时后台算」——Letta 已在主推。这对应 CoALA 里「学习是一个独立的内部动作」的思想，未来会成为标配。

方向三：记忆向数据库层继续下沉。 「Memory-as-a-Database-Service」的形态刚起步。记忆的存储、索引、融合检索、事务、时效天然属于数据库，而 LLM 抽取和冲突消解正被云厂商「吸收」进数据库托管服务。谁能把「一库多能（向量+图+全文+时序）+ LLM 编排」做到开箱即用，谁就占住了基础设施层。

方向四：评测的标准化。 现有基准只测通用召回，缺乏贴近真实业务的、有统一第三方裁判的应用级评测。这是整个赛道公认的短板，也是让「自评 96%」变得可信的前提。

方向五：隐私、同意与可解释。 记忆天然涉及用户隐私。如何在架构层做 consent、脱敏、可删除权、以及「为什么注入了这条记忆」的可解释审计——这既是 CoALA 当年提的「安全性」，也是今天企业客户的刚需和商业护城河。

方向六：多模态记忆。 从文本记忆扩展到 PDF、图像、视频、代码——Supermemory、Cognee 已经起步，但离成熟还远。

结语：地图与公路

如果说 2023 年的 CoALA 画了一张「语言智能体应该长什么样」的地图，那么这三年，社区和商业公司做的，就是照着地图把「记忆」这一块修成了真正能跑车的公路。

演进的主线清晰可辨：从「塞上下文」到「抽事实」，从「纯向量」到「多路融合」，从「应用层框架」到「数据库原生服务」。 而下一段路，大概率会收敛到一个合体形态——统一的记忆 API（mem0 那样的标准）+ 融合检索引擎（Graphiti 那样的能力）+ 数据库原生托管（云厂商那样的形态）。

CoALA 当年说，语言智能体的发展应该有意识地借鉴认知架构数十年的智慧。今天再看，这句话依然成立——只不过「借鉴」已经变成了「落地」，而落地的战场，正在从模型层转移到数据层。
