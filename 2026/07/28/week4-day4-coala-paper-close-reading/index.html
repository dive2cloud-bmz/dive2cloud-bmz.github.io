Agent 记忆系列（04）· 精读 CoALA：用认知科学画出「记忆—动作—决策」地图

论文：《Cognitive Architectures for Language Agents》(CoALA)
作者：Theodore Sumers、Shunyu Yao、Karthik Narasimhan、Thomas Griffiths（普林斯顿大学）
发表：2023 年 9 月，arXiv:2309.02427

为什么值得读这篇

2023 年是 LLM Agent 井喷的一年——ReAct、AutoGPT、Voyager、Generative Agents 层出不穷，每一个都给大语言模型加上记忆、工具、环境反馈，做成能自主行动的智能体。但热闹之下有个尴尬：大家各说各话，缺一个统一的语言去描述「一个 Agent 到底由哪些部件组成」。你没法把两个 Agent 放在同一张坐标系里比较，也说不清某个新系统究竟补上了哪块拼图。

CoALA 要解决的正是这个问题。它的作者阵容值得一提——Shunyu Yao 是 ReAct 和 Tree of Thoughts 的作者，Thomas Griffiths 是认知科学领域的重量级学者。这篇论文的独特之处在于：它不提出新系统，也不刷任何榜单，而是回过头去，从认知科学几十年积累的「认知架构（cognitive architecture）」里，为杂乱生长的语言智能体借来一张成熟的概念地图。

一句话概括它的主旨：用 SOAR、ACT-R 这些经典认知架构的智慧，给语言智能体提供一套统一的「记忆—动作—决策」描述框架，既能回顾已有系统，也能指导未来设计。

核心洞察：LLM 不是 Agent，而是 Agent 的一个「零件」

这是全文的思想枢纽，也是最容易被误解的地方。CoALA 提出一个精妙的类比：LLM 之于语言智能体，就像「生产式规则（production system）」之于经典认知架构。

生产系统是上世纪 AI 的基础——用「如果满足条件，就执行动作」的规则来操作符号字符串。而 LLM 做的事，本质上也是「接收一段字符串，产出另一段字符串」。区别只在于：生产规则是人手写的、确定性的；LLM 是从海量文本里学到的、概率性的。

顺着这个类比，作者得出一个重要结论：光有 LLM 调用，构不成一个 Agent——就像光有一堆生产规则，构不成一个认知架构。你需要把这个概率化的「核心零件」嵌进一个更大的结构里：给它记忆、给它可执行的动作、给它一个决策循环去决定下一步做什么。这个更大的结构，就是 CoALA 框架。

这个视角对今天做 Agent 的人依然有校正作用：如果你把 LLM 本身当成 Agent，你会一直在 prompt 上打转；如果你把 LLM 当成决策循环里的一个推理组件，你才会去认真设计它周围的记忆和动作系统。

CoALA 框架的三根支柱

CoALA 用三个维度刻画任何一个语言智能体。理解了这三根支柱，你就拿到了描述所有 Agent 的通用语言。

支柱一：记忆（Memory）

这是对今天做记忆系统的人最有价值的一节——因为业界现在通用的那套记忆分类，很大程度就是 CoALA 把认知科学的划分引入 Agent 领域后普及开的。它分四类：

工作记忆（working memory） 是当前决策循环里活跃的信息，相当于短期「草稿区」，在各模块和 LLM 调用之间传递状态。它是所有信息流动的中枢。

情景记忆（episodic memory） 存储 Agent 过去的经历——以往的交互轨迹、完成过的任务序列，可在相似情境下被检索复用。

语义记忆（semantic memory） 存储关于世界的事实性知识，既可来自外部语料，也可来自 Agent 自己推理后的沉淀。

程序性记忆（procedural memory） 存储「如何行动」的技能，分两种——隐式地编码在 LLM 权重里，以及显式地写在 Agent 的代码和动作定义里。作者特别提醒：Agent 一般不应随意修改自己的核心代码（显式程序性记忆要慎改），以保证系统稳定。

值得一提的是，今天各类 Agent 产品里的「Skill」机制，在概念上正对应这里的「显式程序性记忆」——人工固化的、可复用的行为知识。

支柱二：动作空间（Action Space）

CoALA 把 Agent 能做的动作切成「对内」和「对外」两类，这个切分非常清晰：

内部动作 有三种，全部围绕记忆展开——推理（Reasoning） 用 LLM 处理工作记忆的内容、生成新信息再写回；检索（Retrieval） 从长期记忆读取信息到工作记忆；学习（Learning） 把新信息写入长期记忆。

外部动作 叫 接地（Grounding），指与外部环境交互，涵盖物理世界、数字环境（调 API、操作网页、查数据库）以及与人类或其他 Agent 的对话。

支柱三：决策流程（Decision-Making）

Agent 运行在一个决策循环里，每一轮分两个阶段。先是规划（Planning）：通过推理和检索，提出（propose）一个或多个候选动作，并对它们评估（evaluate）。再是执行（Execution）：选出最优动作执行，可能是内部动作（改记忆）也可能是外部动作（改环境），结果反馈回工作记忆，进入下一轮。

作者强调，这个「提出—评估—选择—执行」的循环，正是把零散的 LLM 调用组织成有目的行为的关键，也是认知架构留给现代 Agent 最宝贵的遗产。

一个被重新定义的概念：什么是「学习」

CoALA 有一个容易被忽略但影响深远的贡献：它把「学习」定义为向长期记忆写入这个动作，而不只是传统机器学习里的「更新权重」。

这样一来，Agent 的学习形式被大大拓宽了：更新语义记忆（学到新事实）、写入情景记忆（记住这次经历）、修改程序性记忆（改进自己的技能）——都算学习。这个视角对今天做记忆系统的人极有启发：记忆的「写入 / 巩固」，本质上就是 Agent 的学习过程。 这也解释了为什么现在头部记忆产品都把「抽取 + 更新」这条写入流水线做得那么重——它们做的其实是「让 Agent 学会」。

用 CoALA 回看当年的明星系统

论文的后半部分用这套框架系统地「体检」了当时的代表作，展示它的解释力。

ReAct 交错进行推理（内部）和接地（外部动作），但几乎没有长期记忆和显式学习——在 CoALA 框架下看，它主要激活了「工作记忆 + 推理 + 接地」。Voyager 突出在「显式程序性记忆的增长」上——它会把学会的技能写成代码存起来。Generative Agents 重在「情景/语义记忆 + 检索」。Reflexion 则演示了「通过反思写入记忆来实现学习」。而 RAG 类系统，主要激活的是「语义记忆 + 检索」这一路。

这种对照的价值在于：它清楚地显示出，当时大多数 Agent 只用了 CoALA 全部能力的一个子集，从而暴露出研究空白——比如很少有系统认真做情景记忆的组织与遗忘，很少有系统把「规划」做成真正的搜索而非单次 LLM 输出。

论文给出的未来方向

基于这套框架，作者指出了若干当时未被充分探索、值得投入的方向：更结构化、可长期演进的记忆系统（尤其情景与语义记忆的组织、检索与遗忘）；更成熟的学习机制（不止微调权重，还包括如何安全写入和更新各类长期记忆、以及元学习）；更强的决策能力（把规划里的「提出与评估」做得更像经典 AI 的搜索与规划）；推理与检索的深度协同；以及 Agent 的安全性（限制其修改核心程序性记忆、对齐、可解释）。

回头看，这份 2023 年的清单相当有预见性——今天最火的 Agent Memory 赛道，做的几乎就是它当年点名的「结构化记忆 + 安全写入更新」这件事。

总结：CoALA 到底给了我们什么

CoALA 不是一个系统，也不是一个 SOTA 方法，而是一张概念地图和一份路线图。它的核心贡献可以浓缩成三点：

第一，它给了语言智能体一套统一的描述语言——记忆、动作、决策三根支柱，让不同 Agent 可以在同一张坐标系里被比较和设计。

第二，它校正了 LLM 的定位——LLM 是决策循环里的概率化核心组件，而不是 Agent 本身。要造好 Agent，功夫在 LLM 之外的记忆与动作结构上。

第三，它把记忆和学习提到了架构的中心——记忆分四类（工作/情景/语义/程序性），学习被重新定义为「向长期记忆写入」。这个洞察，正是今天整个 Agent Memory 赛道的理论源头。

如果说 2023 年的 CoALA 是一张地图，那么这两年 mem0、Zep、Letta 们做的，就是照着这张地图把「记忆」这一块真正修成了公路。至于这段从论文到产业的演进史，是另一篇 blog 的故事了。

参考：Sumers, Yao, Narasimhan, Griffiths.《Cognitive Architectures for Language Agents》, arXiv:2309.02427, 2023.
